BRAND-001 / ORIGINAL SVG PROPOSALS

Two signatures.
One OFFHOUR.

Both are original, font-independent SVG paths. Neither has been selected. Compare the name, silhouette and readability at the sizes below.

A / The wordmark

Quiet confidence

Shop / Bag

Navigation / 180px wide

Small size / 110px wide

One color / solid black; no grayscale filter

Design choices

Custom geometric uppercase letters, rounded rectangular O counters, a consistent stroke weight and deliberate spacing. The name leads without a separate emblem, supporting Design A’s clarity.

Tradeoff

Its restraint may feel less distinctive as a tiny icon; it is intended to be read as the full name.

B / The O/H lockup

A mark of your own

Shop / Bag

Navigation / 180px wide

Small size / 110px wide · symbol / 24px

One color / solid black; no grayscale filter

Design choices

An open octagonal O encloses an H, paired with the name. The break in the perimeter suggests stepping outside a fixed frame; the symbol can be used separately in small spaces.

Tradeoff

A geometric O/H emblem is a familiar visual idea. Keep it paired with the name while recognition develops; no recognition or trademark clearance is established.

Open original SVG B ↗

Review before choosing.

Both use a single flat fill, with no gradients, fine hairlines or external fonts. The black versions use explicit black vector artwork rather than a visual filter. These are design proposals, not trademark clearance. The storefront still uses its existing text placeholder until you choose.
